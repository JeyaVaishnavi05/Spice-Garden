# 🍽️ Spice Garden – Restaurant Website

Spice Garden is a modern and responsive restaurant website developed to provide users with an engaging digital experience for exploring restaurant information and menu offerings.

The project focuses on creating a visually appealing interface with structured layouts, interactive elements, and dynamic menu management using MongoDB. It demonstrates the process of building a restaurant platform where menu data can be stored, retrieved, and displayed efficiently.

---

## 🚀 Features

### 👤 User Features
- Responsive restaurant homepage design
- Explore restaurant details and offerings
- Dynamic menu display
- Organized food categories for better navigation
- Smooth and consistent user interface
- Header and footer navigation across pages

### 🛠️ Menu Management
- Store menu details dynamically using MongoDB
- Fetch and display menu items from the database
- Efficient management of restaurant menu information
